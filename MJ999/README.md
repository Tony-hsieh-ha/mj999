# 智能配對系統

一個採用黑金配色的高質感智能配對系統，支援玩家報名、管理後台和 LINE Notify 通知功能。

## 🎯 功能特色

### 玩家功能
- **簡單報名**：輸入暱稱，選擇金額即可完成報名
- **即時狀況**：查看目前報名狀況和等待人數
- **防重複報名**：系統自動檢查避免重複報名

### 管理後台
- **報名統計**：顯示總報名人數和待配對人數
- **手動配對**：一鍵為前4名等待玩家配對
- **名單管理**：查看所有報名記錄，可刪除單一報名
- **清空功能**：一鍵清空所有報名記錄

### 通知功能
- **LINE Notify 整合**：預留通知功能介面
- **即時通知**：新報名和開桌時自動發送通知

## 🎨 設計風格

- **黑金配色**：高質感的黑色背景搭配金色點綴
- **現代UI**：採用漸層效果和動畫過渡
- **響應式設計**：支援手機、平板和桌面設備
- **直觀操作**：簡潔明了的使用者介面

## 🚀 快速開始

### 1. 下載檔案
將所有檔案下載到同一個資料夾中：
- `index.html` - 主頁面
- `style.css` - 樣式檔案
- `script.js` - JavaScript 功能檔案
- `README.md` - 說明文件

### 2. 開啟系統
直接用瀏覽器開啟 `index.html` 即可使用。

### 3. 玩家報名
1. 在「玩家報名」頁面輸入暱稱
2. 選擇報名金額（$100, $200, $300, $500）
3. 點擊「確認報名」

### 4. 管理後台
1. 點擊「管理後台」查看報名名單和配對狀況切換到管理頁面
2. 查看報名統計和名單
3. 當有4人以上等待時，點擊「手動開桌」

## 📱 LINE Notify 設定

1. 取得 LINE Notify Token（從 [LINE Notify 官網](https://notify-bot.line.me/)）
2. 在管理後台點擊「LINE Notify 設定」
3. 輸入您的 Token
4. 系統會自動測試發送通知

## 💾 資料儲存

系統使用瀏覽器的 Local Storage 儲存資料：
- **報名記錄**：所有玩家的報名資訊
- **配對記錄**：已配對的記錄
- **設定資訊**：LINE Notify Token 等設定

**注意**：資料僅儲存在當前瀏覽器中，清除瀏覽器資料會遺失所有記錄。

## 🔧 技術規格

- **前端技術**：HTML5, CSS3, JavaScript (ES6+)
- **CSS 框架**：純 CSS（無外部依賴）
- **資料儲存**：Local Storage
- **響應式設計**：CSS Grid + Flexbox
- **瀏覽器支援**：Chrome 60+, Firefox 55+, Safari 12+, Edge 79+

## 📋 使用流程

```

```

## 🎮 系統狀態

- **等待中**：玩家已報名，等待開桌
- **遊戲中**：玩家已在桌上遊戲
- **已完成**：遊戲結束（可手動更新狀態）

## 🔒 安全注意事項

- LINE Notify Token 請妥善保管
- 建議在正式環境使用 HTTPS
- 定期備份重要的報名資料
