## 🎯 配對約局系統 (核心功能)

### 功能特色
- **智能約局** - 創建約局，自動配對玩家
- **時間管理** - 精確的時間約定和排程
- **成桌通知** - 自動通知玩家成桌
- **LINE Notify整合** - 即時推播通知

### 使用流程

#### 創建約局
1. 點擊「配對約局」進入約局系統
2. 填寫基本資訊：
   - 主持人暱稱
   - 約局名稱 (如：今晚8點遊戲局)
   - 遊戲類型 (卡牌/桌遊/益智/策略遊戲)
   - 金額設定 ($50-$500)
   - 約局時間 (可選未來時間)
   - 遊戲地點
   - 備註說明

#### 加入約局
#### 👥 加入約局
1. 在約局列表中找到想加入的約局
2. 點擊「加入約局」按鈕
3. 輸入您的暱稱
4. 系統自動確認加入

#### 🔔 通知系統
- **新約局通知** - 有新約局創建時通知
- **加入通知** - 有人加入約局時通知
- **成桌通知** - 4人滿員時通知所有玩家
- **開始通知** - 遊戲開始時通知
- **提醒通知** - 開始前30分鐘自動提醒

#### 📊 狀態管理
- **等待中** - 還可以加入玩家
- **已滿員** - 4人滿員，準備開始
- **進行中** - 遊戲正在進行
- **已過期** - 超過約定時間

## 🛠️ LINE Notify 設定

### 取得 Token
1. 前往 [LINE Notify 官網](https://notify-bot.line.me/)
2. 登入 LINE 帳號
3. 點擊「產生 Token」
4. 選擇「透過 Chatbot 接收通知」
5. 複製產生的 Token

### 設定步驟
1. 在配對約局系統中找到「通知設定」區域
2. 輸入您的 LINE Notify Token
3. 選擇要接收的通知類型
4. 點擊「儲存通知設定」

### 通知範例
```
新約局：今晚8點遊戲局
時間：3/25 20:00
地點：本店A區01桌
金額：$100
還需要 3 位玩家
```

## 💡 使用技巧

### 約局命名建議
- 包含時間：如「今晚8點遊戲局」
- 包含地點：如「A區01桌約局」
- 包含金額：如「$100中額局」

### 提高成桌率
- 選擇熱門時段 (晚上7-10點)
- 設定合理的金額
- 提供詳細的地點說明

### 主持人權限
- 可以開始遊戲 (滿4人時)
- 可以取消整個約局
- 可以踢除不當玩家

## 🔧 技術支援

### 系統需求
- 現代瀏覽器 (Chrome, Firefox, Safari, Edge)
- 網路連線 (用於 LINE Notify)
- Local Storage 支援 (用於資料儲存)

### 常見問題

**Q: 資料會遺失嗎？**
A: 資料儲存在瀏覽器本地，清除瀏覽器資料會遺失。建議定期備份重要約局資訊。

**Q: LINE Notify 沒收到通知？**
A: 請檢查 Token 是否正確，以及通知設定是否開啟。

**Q: 可以修改約局時間嗎？**
A: 目前不支援修改，需要取消後重新創建。

**Q: 如何刪除過期的約局？**
A: 系統會自動標記過期，也可以手動取消。
