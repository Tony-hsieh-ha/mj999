## 🚀 LINE Login 實際設定

### 申請 LINE Login Channel

1. **訪問 LINE Developers Console**
   - 網址：https://developers.line.biz/console/
   - 使用 LINE 帳號登入

2. **創建新 Provider**
   - 點擊 "Create new provider"
   - 選擇 "LINE Login"
   - 填寫基本資訊

3. **創建 Channel**
   - Provider 名稱：智能配對系統
   - Channel 類型：LINE Login
   - 選擇 Email 登入

4. **設定 Callback URL**
   - 在 "LINE Login" 分頁
   - Callback URL：`https://[您的域名]/line-login.html`
   - 網址需要與實際部署網址一致

### 修改程式碼

在 `line-login.html` 中找到：
```javascript
const LINE_LOGIN_CONFIG = {
    channelId: 'YOUR_CHANNEL_ID', // 替換為實際 ID
```

替換為您的實際 Channel ID。

## 🔧 快速部署指令

### Vercel 快速部署
```bash
# 安裝 Vercel CLI
npm i -g vercel

# 部署
vercel --prod
```

### Netlify 快速部署
```bash
# 安裝 Netlify CLI
npm i -g netlify-cli

# 部署
netlify deploy --prod --dir .
```
